# Taxi-Booking-System
The BSc IT Level 4 Assignment 2 project for The Introduction to Software Engineering course. Utilizes Python for code and Tkinter for the GUI. SQLite is utilized to store user data.

How to run:

Click CTRL+f5 to run the program in VSCode

From there, Registering and Logging in as a Customer is straightforward, put valid information into the Registration fields and enter the chosen password when logging in.

To run have:

  - Python 3.14.0
  - Tkinter and all other imports in app.py imported
  - Connected to SQLite
  - Running in VSCode
